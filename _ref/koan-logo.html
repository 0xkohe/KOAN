KOAN — Identity

開かれた円と、
ひとつの問い。

円相は一息で描かれ、閉じないまま残される。KOAN ではその開口に プロンプトの › が座ります。手元の PC に閉じた環へ、 電話から問いを一つ差し入れる — サービスの形そのものを一文字に収めたマークです。

Mark 円相 + プロンプトキャレット  ·  Accent Action Blue #0066cc

Concept

マークが担う三つの意味

公案

閉じない円

禅の円相。完結を拒む一筆が、答えを配るのではなく問いを扱う道具であることを示します。

Prompt

開口に座る ›

ターミナルのプロンプトであり、送信の合図でもある。外に開いた唯一の口 — tailnet へ公開されるひとつのポートです。

One breath

起筆から離筆へ

右下で太く着地し、右上で細く抜ける。一息で引かれる線は、プロジェクトごとに 1 ターンずつ直列で走る Gateway の挙動に重なります。

Lockups

ロックアップ

横組みが基本形。マークの枠はフォントサイズの 1.16 倍、マークと文字の間隔は 0.42 倍で固定します（外形は大文字高の約 1.28 倍になります）。

Small sizes

SVG

円相は currentColor、キャレットは継承された stroke で色が決まります。親要素に color と stroke を与えるだけで全バリエーションを作れます。

<svg viewBox="0 0 120 120" xmlns="http://www.w3.org/2000/svg"
     style="color:#1d1d1f; stroke:#0066cc"
     role="img" aria-label="KOAN">
  <!-- enso: 起筆 13 → 離筆 5.2 / 右方 50° を開口 -->
  <path fill="currentColor" stroke="none" d="M103.96 80.5 … Z"/>
  <!-- prompt caret -->
  <path d="M97 51.5L105 58L97 64.5" fill="none" stroke-width="6.5"
        stroke-linecap="round" stroke-linejoin="round"/>
</svg>

完全な path データはこのページのソース内 #koan-ring（1,380 字）にあります。ファイル化するなら apps/web/public/koan-mark.svg と icon-180 / 192 / 512.png、favicon.svg を推奨。
