Ordered. Predictable.

Requests within a project run in FIFO order, while separate projects can move in parallel.

Your history stays local.

Conversations and execution events are stored in SQLite on your computer, ready when you reconnect.

Only where you allow.

Projects are limited to approved roots, with real-path validation to keep agents inside the boundaries you set.

Simple setup

Three steps from
computer to pocket.

All you need is Node.js, pnpm, Deno, and Tailscale. Add KOAN to the development environment you already use.

Set up KOAN

Install dependencies and choose the project roots KOAN may access.

pnpm run setup

Start the gateway

Build the React PWA and Deno gateway, then run them on your computer.

pnpm start

Pair your phone

Scan the QR code and connect securely with a single-use pairing code.

Scan & pair
